# Content Approvals Converge on Review Workspaces

**Status:** Accepted

BSM will use Review Workspace as the single domain model for document approval. A review of one document is a one-document workspace; standalone Content Approval records will not remain a separate creation path. The consolidated admin area is named **Content Approvals**, while each record inside it remains a Review Workspace. Active legacy approvals convert to one-document workspaces, while completed or archived approvals remain read-only history. This removes competing reviewer, status, and comment workflows while preserving the ability to present a lightweight single-document experience.

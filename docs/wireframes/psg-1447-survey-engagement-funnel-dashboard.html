Recommended Next Actions

Plain-language guidance for the shop owner and PSG account manager.

Call three urgent customers today. This protects public reviews and keeps routine mail from continuing while an issue is open.

Ask 12 happy customers for reviews. These customers are already satisfied and should not be buried in a source-survey table.

Coach communication updates. Communication is the largest drop-off driver this period.

Design Notes

Implementation should reuse existing PSG cards, badges, filters, tabs, charts, and work-queue rows.

Use one primary action: "Review follow-up list." Keep source surveys one tab away. The Review Mirror stays PSG-operations-only in version one and should not appear in the shop-owner dashboard. This applies Hick's Law, Selective Attention, Progressive Disclosure, Recognition over Recall, and Goal-Gradient.

Information Architecture

  • Rename the default view from Customer Dashboard to Customer Engagement Funnel.
  • Keep raw source surveys behind the Source surveys tab and Review Mirror behind PSG operations access only.
  • Use the nine funnel steps as the main story: courtesy, delivery date given, delivery date met, workmanship, communication, warranty review, repair review, vehicle cleanliness, and fully engaged customer.

Components

  • Reuse PSG metric cards, segmented tabs, filter chips, status badges, chart panels, queue rows, and role-attribution rows.
  • Use PSG paper background, midnight primary panels, ember only for urgent state and focal accent.
  • Use 6px radius, 1px stone borders, and tabular numerals for metrics.

Acceptance Criteria

  • Desktop first screen shows the nine-step funnel, customer satisfaction, response rate, would-recommend rate, survey volume, low-score alerts, and follow-up list.
  • Mobile first screen shows summary metrics and funnel before trend charts.
  • Every funnel stage is marked measured now, derived, or data needed and drills into the matching survey list without exposing unrelated customers.
